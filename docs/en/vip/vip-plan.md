# Hikyuu Donation Support Plan

Hikyuu is a **high-performance quantitative trading computation engine that is free and open source under the Apache-2.0 license; the basic functions such as the core framework, backtesting, indicators and trading models are completely free and unlimited for all users**.

To support the long-term stable maintenance, continuous updating and bug fixing of the project, a **voluntary donation plan** has been launched, providing donating users with **standalone plugin-based value-added features**; all the value-added features do not affect the use and free compilation of the core framework.

# Plugin and License Description

All the donated value-added features are provided as **standalone plugins**, completely separated from the Hikyuu core framework; they **do not modify, intrude into or restrict the core code**, and do not affect the user's own compilation and secondary development.

**Since version 2.8.3, the plugin authorization no longer needs to collect any device hardware identifier**, and the previous device hardware identifier collection mechanism has been abolished accordingly. The authorization verification is changed to be completed online, **supporting an offline grace period of up to 30 days** (when the grace period is exceeded without connecting to the network, you need to reconnect to the network to complete the verification before continuing to use it); **no online verification will be performed during the A-share trading hours**, which does not affect the intraday operation.

**In addition to the financial support, the formal license can also be obtained in other ways; for details, refer to the "How to get a free license and extend the license time" section below.**

If you have private strategies that you want to customize and develop, or you want to use C++ to accelerate the computation (including the inference of various machine learning and AI algorithms, etc.), welcome to contact us.

**Privacy statement**:

1. Since version 2.8.3, the plugin authorization **no longer collects the device hardware feature information** (such as the device fingerprints like the CPU serial number); applying for the authorization does not require agreeing to any hardware information collection.
2. The authorization verification needs to be completed online; in the offline state, there is a **grace period of up to 30 days**, and after it is exceeded, reconnecting to the network for the verification will restore the use; **no online verification will be performed during the A-share trading hours**, and the intraday trading and operation will not be affected by network problems.
3. The hardware information collection mechanism of the earlier versions (before 2.8.3) has been abolished with that version; not applying for the authorization does not affect the normal use of the Hikyuu core framework at all.
