详细描述

Indicator class, concretely implemented by IndicatorImp; when implementing a new indicator, IndicatorImp should be inherited

When implementing a new indicator, the IndicatorImp class should be inherited and the related indicator creation function should be defined, e.g.: 

class Ma: public IndicatorImp {
public:
    MA(size_t);
    MA(const Indicator&, size_t);

    virtual string name() { return "MA"; }
    virtual string toString() { retun "Indicator(MA)"; }
};

Indicator HKU_API MA(size_t n = 30) {
    return Indicator(IndicatorImpPtr(new MA(n)));
}

Indicator HKU_API MA(const Indicator& indicator, size_t n = 30);

◆ setDiscard()

void hku::Indicator::setDiscard ( size_t discard)
inlinenoexcept

Set the number to discard; the value is clamped to size().

When it grows, the extended leading slots are filled with Null; when it shrinks, the previously discarded slots become part of the valid region, so the caller must ensure the data there reflects the current calculation (e.g. by going through _readyBuffer or a fresh _calculate beforehand)
