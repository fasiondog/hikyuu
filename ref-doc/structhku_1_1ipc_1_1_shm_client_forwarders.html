详细描述

The three realtime forwarding callbacks (they are registered after the shmserver plugin connects successfully, and an empty set is registered to unregister them on disconnection)

The implementation of the forwarding target (protocol encoding and decoding, transmission, shared memory reading and writing) is entirely inside the shmserver plugin; the core library does not hold any plugin interface type, it only saves the forwarding functions needed by the market data path (Stock / dataserver) in this struct, and all the forwardings are safe no-ops when they are not registered (standalone mode / the plugin is not installed).
