virtual

Get the raw pointer view of the K-line records of the given range (zero copy, optional implementation)

Only the client shared memory path supports it; [start_ix, end_ix) must be a resolved positive index. It returns false by default, and the caller falls back to the getKRecordList copy path.

参数
marketmarket abbreviation
codesecurity code
kTypeK-line type
start_ixstart index (inclusive)
end_ixend index (exclusive)
out[out] view handle
返回
true is returned when it is supported and hit
