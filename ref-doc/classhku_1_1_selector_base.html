◆ addSystem()

void hku::SelectorBase::addSystem ( const SYSPtr & sys)

Add an existing system strategy instance directly, the very instance is adopted (no clone)

注解
The stock should already be bound. The instance identity is preserved on purpose: the operator-combined selectors (e.g. SE_Add) resolve their prototype intersection by it, and the adopted instances are reused by MultiSystem; use addStock to bind a prototype to new securities instead
参数
sys
