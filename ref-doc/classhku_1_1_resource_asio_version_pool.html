template<typename ResourceType, typename MutexType = std::mutex>
class hku::ResourceAsioVersionPool< ResourceType, MutexType >

Versioned resource pool (the resource type is required to support the version interfaces)

It uses boost::lockfree::queue to implement the lock free idle queue and supports the asynchronous resource acquisition in a coroutine. When the parameters change, the version number is increased automatically and all the idle old version resources are released. 

     **Important constraint**: ResourceType must implement the getVersion() and
     setVersion(int) methods.
模板参数
ResourceTypethe resource type, it must implement the getVersion() and setVersion(int) methods
MutexTypethe mutex type, std::mutex by default (thread safe)
