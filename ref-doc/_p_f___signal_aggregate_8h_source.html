9 * PF is a preset configuration of MultiSystem, so this factory directly returns MultiSystemPtr,
10 * no shell class is introduced. The returned aggregate system runs in
11 * **mode A "Signal Aggregation"**: the sub-systems are pure signal sources on their shadow
12 * accounts (the signal cash is never reset, the shadows run continuously), the parent converts the
13 * suggestions into the executable quantity by the L2 target conversion and orders uniformly on
14 * the parent account (see the MultiSystem class comment for the full semantics).
15 *
16 * Before the three-mode refactoring this preset was carried by PF_WithoutAF, whose name now
17 * stands for mode C (the legacy shared-account Portfolio) again.
18 */
