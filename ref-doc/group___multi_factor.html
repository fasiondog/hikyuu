MultiFactorPtr the given weight multi-factor model pointer

Create a given weight multi-factor model instance, it uses the given factor set and weights for the calculation. Calculation formula: factor = ind1 * w1 + ind2 * w2 + ... + indn * wn Note: it strictly checks whether the size of the weight list is equal to the size of the factor set, and an exception is thrown if they are not equal. This is the key check guaranteeing the correctness of the multi-factor synthesis, ensuring that every factor has its corresponding weight. 

Example:
// Create the given weight model with the factor set
PriceList weights = {0.3, 0.4, 0.3};  // It must match the number of the factors
auto mf = MF_Weight(factor_set, weights, stocks, query);

Filter out the given percentage of the cross-section records that have the smallest turnover amount

注解
The selection is unrelated to the order of the passed cross-section score list: the records with the smaller turnover amount are always the ones filtered out, and the output keeps the score order of the input, so the chained filters (TopN / Group) still select by the score
At least one record is always kept, so a limit of 1.0 keeps the one with the largest turnover amount

min_amount_percent_limitthe minimum turnover amount percentage limit
