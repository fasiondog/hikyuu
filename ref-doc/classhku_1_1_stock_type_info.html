◆ StockTypeInfo() [1/4]

hku::StockTypeInfo::StockTypeInfo ( )

Default constructor, returns Null<StockTypeInfo>().

Initializes tick/tickValue/unit to 1.0 (so unit = tickValue / tick holds) and min/max trade number to 1/1000000, so the default instance is usable instead of an all-zero placeholder that rejects any real order.
