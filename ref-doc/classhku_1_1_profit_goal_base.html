详细描述

Base class of the profit goal strategy

The profit goal is determined before the trade, it is used by the system to execute a sell when the price reaches the profit goal

Subclass goal interface, calculate the goal price when buying

参数
datetimethe current time
pricethe current price
返回
Null<price_t> means no goal is set; 0 means a sell is needed. Note: when there is no position yet (e.g. at the buy moment), returning a pre-calculated goal price based on the current price is also a valid semantic, which will be recorded as the goalPrice of the trade record

◆ _getShortGoal()

virtual price_t hku::ProfitGoalBase::_getShortGoal ( const Datetime & ,
price_t  )
inlinevirtual

Subclass short goal interface, calculate the target price when selling short

参数
datetimethe current time
pricethe current price
返回
Null<price_t> means no short goal is set; the short position is closed when the current price is <= the returned target price. To force a close regardless of price (e.g. a hold-days rule), return the current price so that price <= price always holds. Note that 0 has no effect on the short side (price <= 0 never holds)
