详细描述

Streaming HTTP response class

It is used for the streaming download of a large response body, avoiding loading everything into the memory at once. Both the Content-Length and the Transfer-Encoding: chunked modes are supported.

Applicable scenarios

  • Large file download (>100MB)
  • Realtime data stream processing
  • Server-Sent Events (SSE)
  • Memory limited environment

Inapplicable scenarios

  • Random access to the response data is needed
  • The scenario where the complete data is needed for the processing (such as a JSON parsing)

Performance comparison

  • The memory usage of the traditional way = the file size
  • The memory usage of the streaming way is about 8KB (a constant buffer)
注解
A streaming request is also limited by the configured timeout
HttpTimeoutException and the other network exceptions need to be caught
