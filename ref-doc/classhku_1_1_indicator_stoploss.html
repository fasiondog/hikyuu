overridevirtual

Subclass interface: compute the planned stop-loss price of the current expected trade (a buy); 0 means no stop-loss.

A negative or non-finite result is invalid: the public getPrice returns Null for it and the system opens the trade without stop-loss. Used as a stop-loss it is called on the entry path only (about once or twice per trade, the level is then fixed in the position record); used as a take-profit it is called once per bar while the position is held. The returned level must use the (adjusted) price coordinate of the KData passed to setTO
