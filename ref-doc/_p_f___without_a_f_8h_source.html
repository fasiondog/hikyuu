9 * PF is a preset configuration of MultiSystem, so this factory directly returns MultiSystemPtr,
10 * no shell class is introduced. The returned aggregate system runs in
11 * **mode C "Shared Account Compatibility"**: no shadow account is created, every sub-system
12 * trades directly on the single real account of the parent (shared_tm) and is sized by its own
13 * MM; the parent only gates the entry with the SE, keeps the running pool driven and performs no
14 * L2 conversion (see the MultiSystem class comment for the full semantics).
15 *
16 * The name literally means "portfolio without a fund allocation algorithm", which is exactly what
17 * mode C is. During the three-mode refactoring this factory was temporarily mapped onto mode A;
18 * it is now restored to mode C so that it keeps reproducing the Portfolio of the previous release
19 * with no change on the strategy side, and the mode A preset moved to PF_SignalAggregate.
20 */
