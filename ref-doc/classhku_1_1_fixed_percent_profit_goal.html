Subclass short goal interface, calculate the target price when selling short

参数
datetimethe current time
pricethe current price
返回
Null<price_t> means no short goal is set; the short position is closed when the current price is <= the returned target price. To force a close regardless of price (e.g. a hold-days rule), return the current price so that price <= price always holds. Note that 0 has no effect on the short side (price <= 0 never holds)
