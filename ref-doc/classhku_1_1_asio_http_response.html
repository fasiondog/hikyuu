class HKU_UTILS_API AsioHttpClient

详细描述

HTTP response class

It encapsulates the complete HTTP response information, including the status code, the response headers and the response body. It is suitable for the traditional scenario of loading the whole response body at once.

注解
For a large response body (>100MB) or a memory limited scenario, AsioHttpStreamResponse is recommended
