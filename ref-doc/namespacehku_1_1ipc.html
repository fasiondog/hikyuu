◆ registerShmClient()

HKU_API void hku::ipc::registerShmClient ( ShmClientForwarders fwd)
noexcept

Register / unregister the shm client forwarding callbacks (called when the plugin connects successfully / disconnects; passing an empty set means unregistering)

注解
The registration happens only in the StockManager initialization negotiation period, and the forwarding calls happen in the market data thread; the implementation adopts lock-free publish-subscribe (publish-acquire), and the forwarding side only reads the stable object created in the registration period. The lifetime of the callback object follows the plugin instance, and it must be unregistered before the plugin is destroyed

◆ registerShmMirrorSink()

HKU_API void hku::ipc::registerShmMirrorSink ( ShmMirrorSink * sink)
noexcept

Register / unregister the mirror implementation (pass nullptr to unregister); it is called by the plugin at the single point of start / stop

注解
The pid of the publishing process is recorded on registration, used to exclude the writing of the forked child process (maintaining the single-writer premise)

◆ setInterruptChecker()

HKU_API void hku::ipc::setInterruptChecker ( std::function< bool()> checker)

Set the interruption checker during a long blocking wait (such as waiting for the data service to be ready); true means the wait should be interrupted

In the python environment it is registered by the binding layer (the pending signal is checked after the GIL is re-acquired), so that the wait can be interrupted by Ctrl+C. It is a general facility of the core library: the waiting logic is entirely inside the plugin, and the plugin calls back the implementation registered here through ipc::checkInterrupted().
