#include </Users/fasiondog/workspace/hikyuu/hikyuu_cpp/hikyuu/trade_sys/profitgoal/crt/PG_FixedHoldDays.h>

Profit goal strategy of a fixed holding days

参数
daysthe allowed holding days (counted in trading days), 5 days by default
返回
PGPtr

Once the position (long or short) has been held for at least days trading days, the rule forces an exit on the next bar regardless of price. setTO must be called first, otherwise there is no trading-day list and the rule never takes effect. The forced exit is signalled through the goal value (0 for long, the current price for short), so the goalPrice recorded for such an exit is not a meaningful target price
