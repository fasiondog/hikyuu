Perform a multiple linear regression analysis on a stock

Perform a multiple linear regression analysis on a stock The return of the stock close price is used as the dependent variable, and the input indicators are used as the independent variables for the multiple linear regression. The regression model is: Y = alpha + beta1*X1 + beta2*X2 + ... + betan*Xn

注解
Non-finite handling strategy: if any factor or the return at a time point is non-finite (NaN or ±Inf), the data at that time point is discarded, but it does not affect the data at the other time points or the other factors. A rank-deficient design matrix (exact factor collinearity, which leaves no unique least-squares solution) makes the whole regression fail and returns an empty vector.
参数
stkthe stock object
queryK-line query condition, used to get the time range and data type needed by the regression analysis
indsindicator list, used as the independent variables (factors) of the regression
返回
the regression coefficient vector, the first element is alpha (the intercept), followed by the beta coefficients; an empty vector is returned if the data is insufficient or the regression fails
// C++ example
Stock stk = getStock("sh000001");
Indicator ind1 = MA(CLOSE(), 5);
Indicator ind2 = MA(CLOSE(), 10);
auto result = multi_regression(stk, KQuery(-252), ind1, ind2);
double alpha = result[0]; // Intercept
double beta1 = result[1]; // Coefficient of the first factor
double beta2 = result[2]; // Coefficient of the second factor
