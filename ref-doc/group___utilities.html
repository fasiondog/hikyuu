template<typename ValueT>
bool hku::nearly_equal ( ValueT a,
ValueT b )
inline

#include </Users/fasiondog/workspace/hikyuu/hikyuu_cpp/hikyuu/utilities/arithmetic.h>

Compare two floating-point values within a relative tolerance of a few ULPs.

An absolute epsilon is scale-sensitive: it misses equal-by-intent values at large magnitudes (the ULP of 1e20 is much larger than 1e-9) while falsely matching tiny non-zero values near 0. NaN never matches; infinities are equal only via ==, otherwise the tolerance band becomes inf.

Truncate a number to an integer multiple of the given unit (toward zero).

Returns NaN when the result is not representable (a NaN input, or the quotient beyond the int64 range); callers must reject the order then, instead of clamping a garbage number into a max-size trade.
