template<class EventT>
class hku::AsyncSerialEventProcessor< EventT >

Asynchronous serial event processor

模板参数
EventTthe event type, it needs to support hashing and equality comparison
注解
All the event processing is executed serially in a single thread pool, guaranteeing that only one event is being processed at the same moment
