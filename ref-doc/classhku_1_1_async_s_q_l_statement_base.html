详细描述

Base class of the asynchronous SQL statement

It provides an asynchronous SQL statement execution interface based on the boost::asio coroutine. All the I/O operations (such as exec, moveNext and getColumn) return an awaitable.

注解
It keeps the same bind and getColumn interface design as SQLStatementBase
Only the I/O intensive operations are made asynchronous; the local operations such as the data binding stay synchronous
