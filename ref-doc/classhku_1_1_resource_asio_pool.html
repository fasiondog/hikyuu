template<typename ResourceType, typename MutexType = std::mutex>
class hku::ResourceAsioPool< ResourceType, MutexType >

General shared resource pool - it is suitable for the coroutine environment It uses the boost lock free queue and acquires the resources asynchronously in a coroutine

模板参数
ResourceTypethe resource type, it must support the constructor ResourceType(const Parameter&)
MutexTypethe mutex type, std::mutex by default (thread safe)
