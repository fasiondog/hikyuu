◆ get()

template<typename ResourceType, size_t MAX_POOL_SIZE_LIMIT = 2>
stdx::expected< ResourcePtr, std::string > hku::ResourceTlsVersionPool< ResourceType, MAX_POOL_SIZE_LIMIT >::get ( )
inline

Get an available resource

返回
the expected object of ResourcePtr, it contains the resource pointer on success and the error information on failure
注解
It is a completely lock free operation with an extremely high performance
The returned shared_ptr returns the resource to the pool automatically at its destruction (through the custom deleter)
If the current number of the resources has reached the upper limit and there is no idle resource, the error information is returned
The version is checked when it is acquired from the idle queue; when the version does not match, the old resource is destroyed and a new resource is created
