详细描述

Manual transaction handling; it allows the nested starting of the transaction and requires a manual start and commit; on the automatic exit it does not commit automatically but rolls back!

There must be one effective manual transaction start; multiple nested starts are regarded as one transaction handling. After a manual commit, the transaction must be started manually again if there is new transaction handling.

注解
When nested, it may happen that the inner transaction has been committed but the outer transaction handling fails and is rolled back (only the part of the corresponding transaction handling is rolled back)
