price_t hku::PositionRecord::totalProfit ( ) const

Profit and loss = sell funds - accumulated total trade cost - buy funds

注解
It is valid for the closed records only; Null (NaN) is returned for the ones not yet closed, so callers can tell "unclosed" apart from a genuine zero profit
