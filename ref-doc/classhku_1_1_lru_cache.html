详细描述

template<typename KeyType, typename ValueType, class Lock = NullLock>
class hku::LruCache< KeyType, ValueType, Lock >

LRU (Least Recently Used) Cache implementation (not a strictly defined LRU, in order to improve the concurrent reading performance)

模板参数
KeyTypethe key type, it must support hashing and equality comparison
ValueTypethe value type, it must support the copy and move operations
