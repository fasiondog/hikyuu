template<class TableT, size_t page_size = 100>
class hku::AsyncSQLResultSet< TableT, page_size >

Asynchronous SQL query result set

模板参数
TableTdata structure
page_sizethe number of the data contained in every page

It provides an asynchronous paged query interface based on the boost::asio coroutine. All the I/O operations (such as size, getPage and the iterator access) return an awaitable.

注解
It keeps the same API design as SQLResultSet, only the I/O operations are made asynchronous
It is suitable for the paged query under the high concurrency scenarios
Precondition: same as SQLResultSet — TableT must be bound through the TABLE_BIND macros, which make the ORM layer rely on an integer primary key column named "id"; the flat paged query orders by it (... ORDER BY id LIMIT/OFFSET), so a table without an "id" column is not supported by any query path (paged or not)
