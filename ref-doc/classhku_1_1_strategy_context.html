const vector< KQuery::KType > & ktypeList,
const unordered_map< string, int64_t > & preloadNum = {} )

Constructor

注解
If the security list contains ("ALL") it means all the securities;
  1. The given K-line type list also determines the priority loading order of the K-line data, the earlier ones are loaded first.
  2. When ktypelist or preloadNum is not given, the global config file parameters are used
参数
stockCodeListthe given security code list, e.g. {"sh000001", "sz000001"}
ktypeListthe given K-line data list, e.g. {"day", "min"}
preloadNumthe given preload number, e.g. {{"min_max", 100}, {"day_max", 200}}
