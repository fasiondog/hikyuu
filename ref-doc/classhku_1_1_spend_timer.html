详细描述

Timer for the statistics of the program execution time consumption, it assists in calculating the code execution time

注解
It is not recommended to use it directly, the related utility macros should be used
参见
SPEND_TIME, SPEND_TIME_MSG, SPEND_TIMG_CONTROL
