319 /*
320 * Wait for the background preload thread to exit (idempotent: it returns immediately when the
321 * thread was never started or has already finished). It is only called on the program exit
322 * path, after cancelLoad() and before stopping m_load_tg, so that concurrent access
323 * (TOCTOU/UAF) to m_load_tg from the preload thread and the exit sequence is eliminated. That
324 * thread only loads data and dispatches load events, it performs no nng operation at all, and
325 * it checks m_cancel_load all the way, so it exits quickly after being cancelled; therefore
326 * this join will not become a new blocking point during the static destruction phase on
327 * Windows.
328 */
