price_t hku::SlippageBase::getRealBuyPrice ( const Datetime & datetime,
price_t planPrice )

Get the buy price of the slippage model.

This is a non-virtual wrapper that only calls the subclass _getRealBuyPrice; the System part owns the price authority and validates the result and clamps it into the current bar's [low, high] range before the trade.

参数
datetimebuy moment
planPriceplanned buy price
返回
the buy price of the slippage model
