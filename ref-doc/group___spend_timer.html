详细描述

The utility macros assisting in the statistics of the execution time of a code block; they can be turned off at compile time with the macro HKU_CLOSE_SPEND_TIME=1, or turned on with HKU_CLOSE_SPEND_TIME=0

{
SPEND_TIME(test, "run test");
...
}
