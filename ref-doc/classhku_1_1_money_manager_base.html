详细描述

Base class of the money management (single system/single security form)

Responsibility: given the market data, price, risk and cash of a single instrument (its own account), it decides the buy/sell quantity. The portfolio-level fund allocation (L1/L2/L3) has been migrated to AllocateFundsBase (AF); the two no longer share the class hierarchy, the parameter family or the allocation mode.

Get the quantity of the given trading object that can be sold

参数
datetimetrade date
stockthe trading object
pricetrade price
riskthe risk taken by the new trade; if it is 0, it means the whole loss, i.e. the market value drops to 0 yuan
fromsignal source
注解
The default implementation returns MAX_DOUBLE, i.e. selling everything; this interface is needed only for the multiple position reductions
When the risk is not positive (NaN included, i.e. the price has reached or fallen below the stop loss price), the MMs which do not support multi-trading will liquidate the whole position directly (return MAX_DOUBLE), otherwise the subclass _getSellNumber is left to decide
A finite size is capped at maxTradeNumber; it is not aligned to minTradeNumber, because a dividend or a stock gift may leave an odd lot
