Cross-section Pearson correlation over one day's factor and return values.

Matches ICorr's arithmetic (raw rolling sums): any non-finite value in the input propagates through the sums and yields Null output (via the widened finite-positive variance guard), with no per-stock filtering step. Zero variance also yields Null.

◆ cross_section_spearman()

HKU_API Indicator::value_t hku::detail::cross_section_spearman ( const Indicator::value_t * a,
const Indicator::value_t * b,
size_t n )

Cross-section Spearman rank correlation over one day's factor and return values.

Non-finite pairs (NaN or ±Inf) are dropped before ranking (a stock with a missing factor or return on day t is excluded from that day's cross-section), matching ISpearman. Returns 0.0 when a valid cross-section collapses to zero variance ("no discrimination means no predictive power"), so a downstream MA does not spread NaN. Null is returned when fewer than two valid pairs remain.
