详细描述

Asynchronous manual transaction handling; it allows the nested starting of the transaction and requires a manual start and commit

There must be one effective manual transaction start; multiple nested starts are regarded as one transaction handling. After a manual commit, the transaction must be started manually again if there is new transaction handling.

注解
If it has been started but not committed at the destruction, it rolls back automatically (using a detached coroutine)
