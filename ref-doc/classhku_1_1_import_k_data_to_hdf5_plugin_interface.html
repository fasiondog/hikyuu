Register a new market into the baseinfo database (idempotent: it is skipped and true is returned if it already exists)

参数
marketmarket abbreviation (converted to uppercase automatically)
namemarket name
descriptiondescription (it is recommended to note the time zone, such as "NASDAQ/UTC-5")
index_codethe representative index code of the market (getMarketStock / the trading calendar depend on {market}{index_code})
open1morning opening time HHMM
close1morning closing time HHMM
open2afternoon opening time HHMM
close2afternoon closing time HHMM
返回
true success or it already exists; false failure (invalid license, baseinfo not configured, SQL exception, and so on)
注解
It takes effect only after hikyuu_init() is restarted following the registration; the representative index K-lines must be imported separately

Set the K-line data saving path and the baseinfo database file (sqlite3)

参数
datapaththe directory where the HDF5 K-line data is saved
marketsthe market list whose h5 files need to be initialized
ktypesthe K-line type list to be initialized (DAY/MIN/MIN5/TIMELINE/TRANSDATA)
baseinfo_paththe baseinfo sqlite3 database file path; addMarket / addStockType is not available when it is empty
注解
baseinfo_path and the K-line datapath are independent of each other, it usually points to ~/.hikyuu/stock.db
