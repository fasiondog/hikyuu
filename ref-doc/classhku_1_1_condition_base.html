◆ _isValid()

virtual bool hku::ConditionBase::_isValid ( const Datetime & datetime,
price_t value ) const
virtual

The subclass validity-rule hook, called by isValid and getDatetimeList for every date registered through _addValid

参数
datetimethe queried date
valuethe stored value of the date
返回
true valid | false invalid; the default rule is "the value is finite and > 0"
注解
Override it to apply a custom rule based on the concrete value; the combination operators keep using the built-in "> 0" rule on their sides
