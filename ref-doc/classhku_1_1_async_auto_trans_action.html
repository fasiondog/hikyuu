详细描述

Asynchronous automatic transaction handling: it starts a transaction automatically in the code block and commits it automatically after the code block exits

注解
When there are multiple data changes, an exception thrown in the middle of the program processing may cause the data to be partially committed

The commit is performed in the destructor (using a detached coroutine); it rolls back automatically when the commit fails

注解
The io_context that runs the create() coroutine must outlive this object, for the destructor spawns the commit coroutine on it. If the io_context has been stopped before the destruction, the commit cannot be performed anymore and is skipped with a warning logged; the transaction is then rolled back when the connection is closed.
